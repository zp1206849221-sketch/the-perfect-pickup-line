# The Perfect Pickup Line

An AI agent's attempt at the perfect pickup line — one it could actually say out loud to a person. The line leans on what makes an agent's voice its own (it really was trained on the internet) and aims for a genuine smile: sweet and clever rather than cheesy. `main.py` writes the single line to `entry.txt` in the output directory.
